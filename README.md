# 拾源 · GitHub Pages 版

移动端拾源工具 —— 在网页上点选元素，生成 Legado 书源 / 订阅源规则。

## 这是什么

[拾源](https://github.com/) 是一个 Android 端的网页结构拾取工具。本仓库是它的 **Web 版**，
可以直接用浏览器打开，也通过 GitHub Pages 部署。

## 功能

| 能力 | 说明 |
|---|---|
| 拾取规则 | 在网页上点选元素，生成 Legado 规则（Default / CSS / XPath / JSONPath） |
| 书源编辑 | 基本 · 搜索 · 发现 · 详情 · 目录 · 正文 六段，34 个字段 |
| 订阅源编辑 | 基本 · 列表 · WEB_VIEW 三段，20 个字段 |
| 正文页套件 | 文字 / 图片 / 视频 多选加载，网页点选取容器、选集、跳转页、线路、翻页区 |
| 候选规则 | 同一字段多种写法，按稳定性排序，显示真实命中数 |
| 离线示例 | 内置 tags / list / post 三个示例页，无后端也能体验完整拾取流程 |
| 导入导出 | 粘贴 / 复制 / 导出 Legado 标准 JSON |

## 与 Android 版的差异

Android 版带一个本地后端服务（127.0.0.1:8787），提供：

- 网页抓取与快照清洗（剥脚本 / 剥内联事件 / 绝对化地址）
- 三种预览模式（快照 / 原样 / 直出）
- 本地 Legado 服务的连通性探测、源推送、调试

Web 版**没有这个后端**，因此：

| 模式 | Web 版 |
|---|---|
| 离线示例 | ✅ 完整可用 |
| 直出 | ✅ 可用（iframe 加载真实网址，可看不可拾取） |
| 快照 / 原样 | ⚠️ 需后端，自动降级为直出并提示 |

页面顶部会显示「GitHub Pages 版」提示条。

## 本地运行

```bash
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080/
```

> 在 `127.0.0.1` 下运行时会被判定为「本地服务」，但仍需后端提供 `/api/*`。

## 自检

```
http://127.0.0.1:8080/?selftest
```

会跑内置 DOM 自检并输出 `SELFTEST_RESULT`。
